## Project
ky-pi-agent: a Pi (`@earendil-works/pi-coding-agent`) harness, public and Pi-installable, that makes cheap models (DeepSeek V4 Flash) produce work you'd trust from expensive ones (Bedrock Claude), without the harness becoming the bottleneck.
Every per-turn token must earn its place; prefer a skill, command or subagent over always-on context.
Stack, versions and extension research: `.planning/research/` (STACK.md first). Scope: `.planning/PROJECT.md`.
