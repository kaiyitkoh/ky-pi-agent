## Known breaking changes (from 1.1.0 tarball research, scratchpad `pi-upgrade/`)

1. **0.86.0 TranscriptContext**: `FauxResponseFactory` / `streamSimple` receive `{ messages }` only; read system prompt/tools via `getCurrentSystemPrompt()` / `getCurrentTools()`; `Message` gains `system` role. Breaks `tests/helpers/faux.ts` (~L181-196, 263-268), `tests/integration/budget.test.ts`, `reviewer-contract.test.ts`, `wire-capture.test.ts`; likely `.pi/extensions/diagnostics/{wire,budget,call-model}.ts`.
2. **0.86.0 system prompt in transcript**: `before_agent_start` `systemPrompt` readonly on event; `systemPromptOptions` normalized; `context` event excludes system/tool messages; new `context_with_system` event. Re-verify `harness/index.ts`, `diagnostics/*`, `routing/index.ts`.
3. `ProviderModelConfig` is now a chat/image/classifier union, `api: string` — check the `pi.registerProvider` site.
4. `ctx.home` (used in `safety/paths.ts`) not found in new types — verify.
5. `pi.on()` returns unsubscribe (harmless); `user_bash` fail-closed and `shouldStopAfterTurn` removal (unused); TUI fullscreen default; theme schema 56 tokens (51 required).
6. All ~70 imported symbols still exported.
