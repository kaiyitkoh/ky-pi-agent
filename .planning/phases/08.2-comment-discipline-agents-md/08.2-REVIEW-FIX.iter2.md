### WR-02: The comment-only verifier passes added files silently and never runs by default

**Files modified:** `tests/unit/comment-only-diff.test.ts`
**Commit:** 88331d2
**Applied fix:**
- **Added files.** A file that is new since the ref now fails the test unless it is listed in `COMMENT_DIFF_EXEMPT`. The exempt sanity check accepts paths that were either compared or added.
- **Proof that the check works.** Against `25518c6` with only `harness/index.ts` exempt, the run fails on `harness/comment-rules.ts`. Once that file is declared too, the run passes.
- **Still opt-in.** I did not add a default base ref. The verifier proves that a range is comment-only, so it would fail on any ordinary code change. Failing CI when the ref is empty would make CI fail on every run. The header now says the test is opt-in on purpose and gives the run command.
