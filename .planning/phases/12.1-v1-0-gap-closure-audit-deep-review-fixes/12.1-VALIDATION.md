# Phase 12.1 — Validation Strategy

> Per-phase validation contract. Source: 12.1-RESEARCH.md "Validation Architecture".

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | vitest 4.1.11 |
| **Config file** | `vitest.config.ts` |
| **Quick run command** | `npx vitest run <file> --maxWorkers=2` (one file at a time) |
| **Full suite command** | `npx vitest run --maxWorkers=2` (ONCE, final plan) |
| **Typecheck** | `npx tsc --noEmit` (per plan) |
| **Estimated runtime** | ~215 seconds full suite |

## Sampling Rate

- **After every task commit:** the targeted test file(s) for the area, run sequentially with `--maxWorkers=2`.
- **After every plan:** `npx tsc --noEmit` plus that plan's targeted files.
- **Phase gate:** full suite once, green. The known `audit-concurrency` load flake must be named if it occurs.
- **CPU budget:** never run tests concurrently.
