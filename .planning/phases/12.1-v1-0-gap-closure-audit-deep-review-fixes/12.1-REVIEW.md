- WR-A-2: Regex pattern arguments are glob-classified as file names
- WR-A-3: Exported `GIT_*` variables bypass the git environment check
- WR-A-4: The protected branch can be moved locally from a feature branch
- WR-A-5: The sensitive-read table misses credential stores the user has; environment secrets are unguarded
- WR-A-6: Hook managers and git config locations outside `.git/hooks` and `.git/config` are not detonation targets
- WR-A-7: `--global-setup` and the full run do not enforce the single safety delivery path
- WR-A-8: Tests cannot detect push-destination or confirm-mode regressions
- WR-A-9: Plan mode admits `rg --hostname-bin=<program>`
- WR-A-10: `read-only.ts` breaks the AGENTS.md comment rules and escapes the comment test
- WR-A-11: `check-gh-unauthenticated.sh` reports OK when the gh token cannot be validated
- WR-A-12: The approval dialog has no timeout and does not use `canConfirm`
- IN-A-1: A failed child-guard registration is silent
- IN-A-2: The management confirm truncates the definition shown to the human
- IN-A-3: Comment and reason text reference planning artifacts and test files
- IN-A-4: Protected branch names are hard-coded
- IN-A-5: The "opaque script file" gap is not in the Known bypasses table
