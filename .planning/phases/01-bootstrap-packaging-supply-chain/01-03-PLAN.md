- Default export is a function taking Pi's `ExtensionAPI`, imported as `import type { ExtensionAPI } from "@earendil-works/pi-coding-agent"`.
- `pi.registerCommand(name, { description, handler })` — handler signature `(args, ctx) => void | Promise<void>`. Commands cost **zero** system-prompt tokens (`pi/src/core/system-prompt.ts` contains no reference to registered commands).

| Boundary | Description |
|----------|-------------|
| project directory → Pi resource loader | Pi's project-trust gate decides whether `.pi/**` resources are loaded. `docs/security.md:31` states plainly it is an input-loading guard, **not** a security boundary |
| repo files → third-party clone | What a consumer receives is what git committed, which is not necessarily what is on the author's disk |
