Export `runPi(args: string[], opts?: { cwd?: string; env?: Record<string,string> })` returning `{ stdout, stderr, status }` from `spawnSync` with `encoding: "utf-8"`, `shell: false`, and a 120000 ms timeout. Always merge `--offline` into the arg list unless the caller already passed it, so no test performs a startup network call.

Create `tests/helpers/stub-bin.ts` exporting `withStubBin(stubs: Record<string, { exitCode?: number; stdout?: string; logTo?: string }>, fn: (env) => T): T`. It creates a temp directory, writes one executable stub per key, prepends that directory to `PATH` in the env object it hands to `fn`, and removes the directory afterwards. On Windows the stub must be a `.cmd` shim alongside the POSIX `sh` script, because `spawnSync` without a shell will not resolve an extensionless file on Windows — write both and let PATHEXT pick. When `logTo` is set, the stub appends its own name and its full argv, one line per invocation, to that file — this is how Plan 06 proves the `.npmrc` assertion runs *before* any `pi install`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| working tree → public git remote | Pi writes credentials, session transcripts and audit logs into paths that can land inside the repo |
| test process → developer machine | A test that mutates real machine state (`gh` login, `~/.pi/agent`) damages the developer's environment |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-05 | Information Disclosure | Credential and runtime-state paths committed to a public repo | mitigate | Bidirectional `git check-ignore -q` table test over the full path inventory read at source from `pi src/config.ts:516-566`; content assertion that no committed npmrc carries `_authToken` |
| T-01-06 | Denial of Service (self-inflicted) | A one-directional ignore test swallowing `.pi/extensions/` | mitigate | `MUST_BE_COMMITTABLE` array asserted with equal weight; explicit assertion that no `.gitignore` exists under `.pi/extensions/` |
| T-01-07 | Tampering | Test helpers mutating real developer state (`gh` auth, `~/.pi/agent`, global npm) | mitigate | `withStubBin` prepends a throwaway `PATH` and removes it in `finally`; no helper writes outside a temp directory |
| T-01-08 | Elevation of Privilege | The `evil-postinstall` fixture escaping test scope | mitigate | Fixture is private, dependency-free, never referenced from the root `package.json`, and writes only to a path supplied via `KYPI_EVIL_SENTINEL` |
