## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions marketplace → CI runner | A third-party action referenced by a mutable tag can be replaced with different code between runs, with full access to the checkout and the runner token |
| git checkout → shell interpreter | A CRLF-checked-out script fails on macOS with a misleading "bad interpreter" error, or worse, partially executes |
| CI green signal → developer confidence | A matrix leg that lints but never executes produces a green tick that means nothing |
