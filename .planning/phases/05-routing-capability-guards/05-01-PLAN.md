| table → committed public repo | The map is committed source in a public repository |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | `ROLE_MAP` entries | mitigate | Every `{provider,id}` is resolved against a composed `ModelRegistry` in `tests/unit/routing-map.test.ts`; an id that does not exist fails the build rather than failing at runtime with a refusal the user cannot interpret |
| T-05-02 | Information Disclosure | model ids / provider names in a public repo | accept | Provider ids and public model ids are not secrets; no credential, account id, ARN or endpoint host is written into `schema.ts` — the DashScope workspace-dedicated host stays in `.pi/templates/`, untouched here |
