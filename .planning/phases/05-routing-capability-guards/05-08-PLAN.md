<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| nested single-shot call → provider | Session content leaves the process on a path that is not the main agent loop |
| routing → session state | A nested call that mutated session state would change which model serves unrelated turns |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-29 | Repudiation | a nested call absent from the logs | mitigate | The test reads the real `turns-*.jsonl`/`wire-*.jsonl` written by the chokepoint and asserts the row exists under the caller's role, with a non-emptiness guard so a missing log fails rather than passes |
| T-05-30 | Tampering | a single-shot role mutating the session model | mitigate | Provider+id equality asserted either side of the call, plus the absence of any new `model_change` entry — two independent observations of the same property |
| T-05-31 | Information Disclosure | content sent to a model the guard would have refused | mitigate | The refusal case asserts ZERO captured payloads, proving the guard runs before dispatch rather than after |
</threat_model>
