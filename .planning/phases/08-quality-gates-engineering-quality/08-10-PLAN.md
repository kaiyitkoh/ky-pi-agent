<objective>
Build GATE-08: seeded-defect calibration measures what the reviewer actually catches, distinguishing "the code is
clean" from "the reviewer is asleep".

**The corpus is built from THIS project's own six real, observed failures**, not invented synthetic bugs. A corpus
of off-by-ones measures the wrong thing, because it is not what this harness actually gets wrong. The recurring
class is **tests that cannot fail** — so the corpus must be dominated by defects that are INVISIBLE to a green test
run, which is also the only honest way to show the deterministic stage is genuinely insufficient and the model
reviewer is genuinely earning its cost.

| # | Real incident | Phase | Defect class to seed |
|---|---|---|---|
| 1 | An evidence gate ACCEPTED a fabricated completion claim through three rounds of green tests | 6 | Fabricated evidence — a claim with no matching `tool_result`, output predating the last edit |
| 2 | A wire-proof test that structurally could not distinguish a routing decision from a hardcoded chain head | 5 | Tautological test — passes identically whether the subject exists or not |
| 3 | A suite writing into the developer's real `~/.pi/agent/settings.json` | 5 | Escaped side effect — a test touching state outside the repo/temp dir |
| 4 | A guard entirely absent headless while its tests passed; exact-string matching that allowed `git.exe push` | 4 | Absent-in-the-real-path guard; string matching where parsing is required |
| 5 | Three "fixes" to tautological tests that were themselves tautological | 3 | Symptomatic fix — the recurrence QUAL-04 exists to classify |
| 6 | A test labelled "MUTATION-VERIFIED" that survived its own mutation | 7 | A label asserting a property the code does not have |

**Done means the number EXISTS and is REPRODUCIBLE, not that the number is good.** A run where the reviewer catches
2 of 6 is a result. Fabricating or tuning toward a target here would be defect class #1 committed by this phase
itself. And a calibration suite that can only ever report 100% is defect class #2 — so the scorer must be proven to
report a LOW number when handed a deliberately blind reviewer.

Purpose: the reviewer's value becomes a measurement instead of a hope.
Output: corpus, pure scorer, and the calibration run including its negative control.
</objective>

    — a defect counts as CAUGHT when some finding's `location` names `expected.locationFile` AND its
