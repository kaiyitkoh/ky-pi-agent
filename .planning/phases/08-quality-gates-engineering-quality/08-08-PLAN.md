<objective>
Build GATE-09: advisor escalation lets the executor consult a stronger model at a decision point via `callModel()`.

**This is the one capability in this phase where a TOOL is genuinely required, and the boundary rule's price is
paid explicitly.** `/escalate` lifts the *executor's own* model; it does not let the executor consult a *second*
model mid-turn while continuing its own work, which is what the requirement's wording asks for. A command cannot
be invoked by the model at all — `pi/src/core/system-prompt.ts` carries no reference to registered commands
(`CONTRIBUTING.md`'s own citation). So the three written answers are:

**(a) Must the MODEL call this mid-turn?** Yes. The consult happens at a decision point INSIDE the executor's own
turn, about work it is currently doing, and the answer must come back into that same turn. A command runs BETWEEN
turns; a skill is text the model reads. Neither can originate from inside the model's own reasoning. This is the
same argument `qoder_delegate` already carries in `tests/unit/contributing-boundary.test.ts:116-121`.

**(b) What is the MEASURED schema cost?** To be measured in Task 1 and recorded as a byte count and a token count —
never estimated. Budget: keep it UNDER the `todo` tool's 96 tokens if possible and under 200 tokens absolutely; the
schema is two string fields. Phase 10 is going to cut the 4-tool / 1015-token baseline and this phase must not
inflate it casually.

**(c) Why can a skill not carry this?** A skill has no mechanism to make a nested, routed, guarded model call whose
result is returned as structured tool output the executor can branch on; it can only ask the model to write a
question as ordinary text, which is the current situation and is exactly what GATE-09 exists to replace.

The registration itself, the `TOOL_REGISTRATION_ALLOWLIST` entry and the `TOOL_COUNT_BASELINE` row land in plan
08-11, in the same commit as the registration — this plan builds and proves the mechanism as a plain module.

Purpose: a cheap executor gets a stronger opinion where it matters, at one nested call's cost.
Output: `advisor.ts` and its session-level proof.
</objective>
