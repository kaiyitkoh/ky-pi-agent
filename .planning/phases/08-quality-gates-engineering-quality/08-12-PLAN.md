<objective>
Close the evidence gate's one explicitly-deferred residual. `evidence.ts:136-143` and `docs/WORKFLOWS.md` §4 both
name **Phase 8** as its owner: today an empty commit (`git commit --allow-empty`) or a commit of wholly unrelated
content still ACCEPTS, because distinguishing "the commit contains the work" from "the commit is empty" needs a
diff or a tree hash. The deterministic stage now computes a diff for the reviewer's context contract, so the tree
comparison is nearly free.

**This must not be quietly dropped.** If the gap cannot be closed as specified, the plan's summary must say so
explicitly and the honest wording in `evidence.ts`'s docstring, `index.ts`'s notification text and
`docs/WORKFLOWS.md` §4 must be left intact rather than softened.

Scope discipline: this closes "the commit contains SOMETHING that changed" — a tree comparison. It does NOT and
cannot close "the commit contains THE CLAIMED WORK", which needs a semantic judgement no predicate makes. Say that
plainly in the docstring and in the doc; overstating the closure would be exactly the false-label defect class this
phase's own corpus seeds (`08-CONTEXT.md` incident #6).

Purpose: a completion claim can no longer be satisfied by a commit containing nothing.
Output: a sixth ordered branch, its two-directional tests, and honest documentation.
</objective>
