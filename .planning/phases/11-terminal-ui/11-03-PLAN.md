pi-subagents@0.76.1 event shapes (RESEARCH "Subagents", read from the packed tarball, never executed):
- subagent:async-started payload: id, pid, sessionId, mode, agent, agents[], chain, cwd, asyncDir
- subagent:async-complete payload: id and/or runId, agent, mode, state (complete|failed|stopped), success, timestamp
- Foreground runs are visible only as Pi tool_execution_start/end with toolName "subagent".
- subagent:child-status and subagent:foreground-complete are NOT counted: children belong to an already-counted run, and the foreground run is already tracked by its tool call (counting either would double).

Pi exec semantics (dist/core/exec.js:10-75): spawn with shell:false, resolves { stdout, stderr, code, killed }; a spawn failure resolves code 1 rather than rejecting. git exits 128 outside a repository.
