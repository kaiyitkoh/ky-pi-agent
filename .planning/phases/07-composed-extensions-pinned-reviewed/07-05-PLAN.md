<objective>
Prove ROADMAP criterion 4 — a parallel subagent in an isolated git worktree can **build**, not
merely check out — against a real temp repository, a real `git worktree add`, and the real hook
script this repo ships.

the trap: "asserting the worktree instead of proving it". `git worktree add` copies no untracked

failure BEFORE applying the remedy, so the remedy's effect is attributable — the same
both-directions discipline `tests/unit/npmrc-policy.test.ts` Group B uses for the `ignore-scripts`
control ("without this, the assertion above could be passing because the fixture is inert").
