<objective>
Establish, and bind to the pin, the evidence that EXT-03 (background execution without blocking)
and EXT-04 (mid-run steering without killing the run) are real mechanisms in the pinned
`pi-subagents`, and assert separately that this repo's own composition enables them.

Purpose: these two requirements are about third-party runtime behaviour. 07-RESEARCH.md's
Addendum A6 is blunt about the limit — "Nothing was executed; no Pi install, no credentials, no
`npm install`. All findings above are static source reads." The honest discharge has three parts,
and this plan does the two that are possible offline:

1. **The mechanism exists**, read from the package's own source at the exact pinned version:
   `async` is an optional boolean on the `subagent` tool's schema (`src/extension/schemas.ts:327`),
   a dedicated `subagent_wait` tool exists (`src/runs/background/wait-tool.ts`), and the steering
   channel is `SUBAGENT_STEERING_MESSAGE_TYPE` / `handleSubagentSteeringNotice`
   (`src/extension/steering-notices.ts`). Recorded with `file:line`, re-read at execution time.
2. **This repo composes it**: an agent file exists, `agentScope` loads it, and the tool that
   accepts `async` is one of the four `pi-subagents` registers.
3. **The behaviour was observed** — not possible here. That is `RB-07-01`, written by plan 07-13,
   marked OUTSTANDING, and never claimed.

The mechanism this plan must get right is the BINDING. A citation table that nobody re-checks
when the version moves is worse than no table: it looks like evidence and is a memory. So the
test asserts every evidence row names the version currently pinned in `.pi/settings.json` — a
version bump without a re-read turns the suite red. That is the same doc-to-code both-directions
discipline `docs/ROUTING.md` and `docs/SAFETY.md` already carry in this repo.

**No third-party code is executed by this plan.** Source is obtained with `npm pack` plus
`tar -xf`, which runs no lifecycle scripts, and is read. Running `pi-subagents`' own test suite
would be executing third-party code, which belongs after plan 07-10's legitimacy checkpoint and
is named in the runbook instead.

Output: an evidence section in `docs/EXTENSIONS.md`, `tests/unit/subagent-capabilities.test.ts`.
</objective>
