<objective>
Close EXT-05 and EXT-06 with a capability-to-evidence registry, and commit the model-facing tool
baseline Phase 10 will measure its cuts against.

Purpose: EXT-05 names eight capabilities — plan mode, todo tracking, background bash, LSP
diagnostics, structured user questions, web lookup, session search, loop detection. EXT-06 adds
that Pi's bundled examples are preferred wherever they cover the need. Both are claims about
composition, and both are checkable offline: each capability resolves either to a vendored file
at an auto-discovered path or to a pinned `packages[]` entry, and which of the two it is IS the
EXT-06 answer. A row whose evidence checks `packages[]` for a capability that should have been
vendored is the exact regression this phase is named after, caught mechanically.

The baseline is 07-CONTEXT.md decision 6: every extension registering a tool costs per-turn
schema tokens on every request, Phase 2 measured a ~1,850 tok/turn floor, and Phase 10 does the
cutting. Phase 7 does the counting. A count that lives only in a research document is not a
baseline; a committed registry that fails the build when it drifts is.

Output: `tests/unit/extension-composition.test.ts`, `tests/unit/tool-count-baseline.test.ts`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| vendored source → npm dependency | a future change quietly replacing a reviewed vendored copy with an unpinnable package |
| tool registry → every provider request | each recorded tool's schema rides in every request; an unrecorded tool is an unbudgeted cost |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-46 | Tampering | a vendored capability silently becoming an npm dependency with a caret residual | mitigate | Direction 2 of the composition test asserts each vendored row's `npmAlternative` is absent from `packages[]`, falsified by actually adding one |
| T-07-47 | Spoofing | an untracked scratch file satisfying a capability row | mitigate | Evidence discovery uses `trackedFiles` (git's index view), not `existsSync` |
| T-07-48 | Repudiation | a tool count copied from a research document rather than read from source | mitigate | Every npm row's tool names must carry a `file:line` citation recorded in the summary, obtained from the tarball at the pinned version in this session |
| T-07-49 | Denial of service | an extension growing a new model-facing tool unnoticed | mitigate | Direction 1 grep-enforces the vendored side exactly; Direction 3 fails when a package appears in `packages[]` with no baseline row |
| T-07-50 | Repudiation | claiming the npm half of the baseline is enforced when it is recorded | mitigate | The docstring states the boundary explicitly, following the `docs-policy.test.ts` precedent; the acceptance criteria require it |
</threat_model>
