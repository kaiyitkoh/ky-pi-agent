executable on a machine that holds this developer's git credentials and, on the work laptop, live

before install and explicitly non-auto-approvable. That gate is Task 2 of this plan, and it is the
only human gate in the phase — every other plan in Phase 7 runs autonomously.

`docs/EXTENSIONS.md`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → executable code in this repo | `pi install` fetches and makes executable five third-party packages that run with full user permissions |
| package name → installed identity | an `[ASSUMED]` name resolving to a typosquat rather than the intended package |
| install process → supply-chain controls | an install that rewrites `.npmrc` or `npm_config_*` state and silently disarms `ignore-scripts` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-41 | Elevation of privilege | npm lifecycle scripts executing during `pi install` | mitigate | `sh bin/bootstrap.sh --assert-hardening` runs immediately BEFORE the install (Task 1) and again AFTER it (Task 3); a non-zero exit before install stops the plan outright |
| T-07-42 | Spoofing | a typosquat or slopsquat resolving from an `[ASSUMED]` package name | mitigate | Task 2 is a blocking, explicitly non-auto-approvable human checkpoint verifying all five names against their npm and GitHub pages, per the package-legitimacy protocol |
| T-07-43 | Tampering | the install silently rewriting `.npmrc` or `.pi/npm/.npmrc` | mitigate | `git status --porcelain` is asserted clean for both files after the install, and the hardening assertion is re-run afterwards |
| T-07-44 | Repudiation | claiming a `pi list` match that was never observed | mitigate | The fallback path is explicit: record the failure, verdict UNVERIFIED, hand `RB-07-02` to plan 07-13; the acceptance criteria admit only an observed MATCH or a recorded failure |
| T-07-45 | Information disclosure | third-party extension code running in a session with access to this repo and the developer's git credentials | accept | Recorded in `docs/EXTENSIONS.md`; every installed package was source-reviewable, license-audited and lifecycle-script-checked in plan 07-01, and the two packages with the largest tool surface are named as Phase 10 cut targets |
| T-07-SC | Tampering | npm/pi package installs | mitigate | slopcheck classification carried from 07-RESEARCH.md (zero `[SLOP]`), plus the blocking human checkpoint in Task 2 covering every `[ASSUMED]` and `[SUS]` package before install |
