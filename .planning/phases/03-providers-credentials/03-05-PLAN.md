<objective>
Prove offline the two things about Bedrock and about R1 that can be proven offline — and stop
there, loudly.

Purpose: `aws sso login` alone sets **no** environment variable; it writes a token cache under
`~/.aws/sso/cache/`. Without `AWS_PROFILE` literally set, Pi reports no Bedrock credentials
even though the AWS SDK would resolve fine. `auth.json`'s `credential.env.AWS_PROFILE` is
checked *before* process env, survives a fresh shell and contains no secret — which is why it
is templatable in a public repo. That resolution is provable here. Whether a live SSO token
resolves on the work laptop is not, and is `RB-03-03`.

For R1: two researchers reached opposite conclusions because they answered two different
questions. Pi 0.84.1 with the built-in catalogue **can never send** `reasoning_effort: "low"` —
`thinkingLevelMap.low` is `null`, `getSupportedThinkingLevels` drops it and
`clampThinkingLevel("low")` returns `"high"`. This plan proves the one-line `modelOverrides`
unclamp works, which is what makes `RB-03-04` executable rather than merely described. It does
not, and must not, answer the token-count question.

Output: `tests/unit/bedrock-auth.test.ts` and `tests/unit/r1-unclamp.test.ts`.
</objective>
