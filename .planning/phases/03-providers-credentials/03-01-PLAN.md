  <action>
Create `tests/helpers/models.ts` exporting `withModelsConfig(opts, fn)` — an async
disposable that hands a callback a fully offline model registry and cleans up afterwards.

`opts` accepts:
- `models` — either an absolute path to a models config file (the shipped template) **or** a
  plain object which the helper serialises to `<agentDir>/models.json`;
- `auth` — an optional plain object serialised to `<agentDir>/auth.json`; when omitted the
  path is passed anyway and simply does not exist, which `ModelRuntime` tolerates;
- `env` — an optional `Record<string, string>` applied to `process.env` for the duration of
  the callback and restored in the `finally`. Restoration must **delete** keys that did not
  exist before rather than setting them to `""` — an empty string is not the same as absent
  and the Bedrock `??` chain (RESEARCH §Q5.4) treats them differently.

The handle passed to `fn` carries at least: the created `ModelRuntime`, its model registry,
`agentDir`, `modelsPath` and `authPath`, plus a `requireModel(providerId, modelId)` function
that **throws** with the provider id, the model id and the remedy in the message when the
model does not resolve. Never return `undefined` from it — an unresolved model that returns
`undefined` is how Assumption A7's renamed-id hazard becomes a silent skip.

Construction rules, all load-bearing: `refreshOnCreate: false` (this is what makes the helper
offline — no catalogue fetch at construction time); the agent dir is a fresh
`mkdtempSync` under a `kypi-` prefix and is the only path the helper ever removes;
`rmSync(..., { recursive: true, force: true, maxRetries: 3 })` inside a `try`/`catch` that
swallows, because a leftover temp dir on Windows is noise and not a failure.

Open the file with the house module docstring: what it is, why it exists (the composed-model
rule of Trap T6 — a test that asserts the template's bytes proves nothing because typebox
accepts `supportsStoore` silently), and `[VERIFIED:]` / `[CITED:]` citations on the
`ModelRuntime.create` option semantics. Name PROV-01, PROV-03, PROV-04, PROV-06 and PROV-07
as the requirements this seam serves.

Do **not** import or mention `ModelRuntime` from anywhere under `.pi/extensions/` — this
helper lives under `tests/`, where the DIAG-03 chokepoint lint does not reach, and that is
precisely why it belongs here.
