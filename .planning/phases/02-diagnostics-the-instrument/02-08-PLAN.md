Modify `.pi/extensions/diagnostics/index.ts` to register three more hooks, each through `safeHandler`, each block-bodied with no value return.

Maintain a small module-scoped per-turn accumulator keyed by nothing more than "the turn currently in flight" — a single mutable record is sufficient because the main loop is serial. Fields: `startedAt`, `corr`, `message`, `thinkingLevel`.

- `turn_start` — stamp `startedAt` from the event timestamp when present and `Date.now()` otherwise, capture `ctx.thinkingLevel`, and clear any stale message from a previous turn.
- `message_end` — when `event.message.role` is `"assistant"`, store the finalized message and the current correlation id on the accumulator. Add a comment stating explicitly that this handler returns nothing: a returned `{ message }` would replace the finalized message, and the replacement must keep the same role (`types.ts:1097-1100`). Diagnostics never replaces a message; only the prose retry (plan 02-09) interacts with this hook's semantics, and it does so with `sendUserMessage`, not a replacement.
- `turn_end` — compose the row with `composeTurnRow({ kind: "turn", role: "session", sessionId, corr, message, model, latencyMs, turnIndex: event.turnIndex, toolResults: event.toolResults.length, thinkingLevel })` and append it to the turns stream with `appendJsonl(ctx.cwd, TURNS_LOG_BASE, row, { rotateBytes: TURNS_ROTATE_BYTES, maxRotated: MAX_ROTATED_FILES })`, then increment the rows-written counter and reset the accumulator. When no assistant message was seen for the turn, append a row carrying `event: DIAGNOSTICS_ERROR_EVENT` and a `where` of `"turn_end.no_message"` rather than silently skipping — a missing row must be visible.

Resolve the model for `composeTurnRow` from `ctx.model`; when it is unavailable, fall back to a minimal shape carrying the message's own `provider` and `model` strings and zero cost rates, and set an `event` field recording the degradation, so a zero cost is never silently indistinguishable from a computed one.

Update the LAYOUT paragraph of the module docstring to name `turns.ts` and DIAG-04.
