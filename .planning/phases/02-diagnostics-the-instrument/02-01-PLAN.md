| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | Tampering | `withFauxSession` / `withTempLogCwd` cleanup | mitigate | Only paths returned by `mkdtempSync` with a `kypi-` prefix are removed; `rmSync` is never called on a caller-supplied path |

| T-02-01-04 | Repudiation | a helper that skips when a prerequisite is missing | mitigate | Throw-never-skip, per `tests/helpers/pi.ts`; an acceptance criterion greps for `.skip` and requires zero hits |
