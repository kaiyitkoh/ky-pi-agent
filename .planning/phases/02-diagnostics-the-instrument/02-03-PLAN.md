## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| diagnostics writer → working tree | Every byte this module writes lands inside a directory that is one `git add -f` from a public repo |
| concurrent subagent processes → one shared log file | Multiple Pi processes append to the same path with no lock |
| log directory → filesystem outside it | Rotation and prune manipulate paths and could follow a symlink out |
| a throwing handler → the operator | Pi swallows handler exceptions, so a broken instrument looks identical to a quiet one |
