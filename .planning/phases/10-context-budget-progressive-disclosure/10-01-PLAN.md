Build the instrument Phase 10 measures everything with, and take the BEFORE reading with it.

Output: a `floor` field and line in `/budget`, a composed faux-session helper, a floor/attribution integration test, and a "Per-turn floor" section in `docs/DIAGNOSTICS.md` holding the BEFORE numbers with method.

Decisions recorded here (Claude's discretion per 10-CONTEXT.md):
- The recorded unit is `/budget`'s formula (`computeBudget`: system prompt chars + per-tool `name + description + JSON(parameters)` chars, `Math.ceil(chars/4)`). The wire estimate (`toToolDeclaration` JSON) is recorded beside it once, labelled, and never mixed into a comparison (RESEARCH Pitfall 7).
- Absolute paths (temp cwd, temp agentDir, repo root which holds Pi's install path for the `docs` section) differ per machine and per CI OS (ubuntu, windows, macos). Every number the tests assert or the doc records is computed on a path-NORMALISED system prompt (each path, in both slash forms, replaced by a fixed placeholder `<cwd>`, `<agent>`, `<repo>`, longest first). Raw this-machine numbers may be recorded beside them, labelled.
- Per-extension attribution = floor(bare Pi + AGENTS.md + that one entry point) minus floor(bare Pi + AGENTS.md); skills are attributed as their own row by toggling the skills option.
</objective>
